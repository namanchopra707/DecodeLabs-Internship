# Task 3: Customer Segmentation using K-Means Clustering

## Objective
Use K-Means Clustering to group customers based on their purchasing behavior. The data was preprocessed, standardized, reduced using Principal Component Analysis (PCA), and then clustered into customer segments using K-Means.

## Workflow
1. Load the dataset.
2. Select numerical features.
3. Standardize the data.
4. Apply PCA.
5. Find the optimal number of clusters.
6. Train the K-Means model.
7. Visualize the clusters.
8. Analyze and interpret the customer segments.

## Output
The model identified four customer segments:
- Budget Customers
- Bulk Customers
- Premium Customers
- High-Value Customers

The final segmented dataset was exported as `customer segmentation results (task 3).csv`.
